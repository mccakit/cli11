Detailed Description

The heavier validators: type checks, set membership, and unit parsing.

These sit apart from the validators partition because they are templated on the option's type or on a container of allowed values, and because most carry enough machinery to be worth isolating:

  • cli::type_validator_t checks that a value parses as a given type.
  • cli::bound_t clamps a value into a range rather than rejecting it.
  • cli::is_member_t checks a value against a set, optionally case- and underscore-insensitively.
  • cli::transformer_t and cli::checked_transformer_t map a value through a lookup table.
  • cli::as_number_with_unit_t and cli::as_size_value_t parse "10kb" style values.

Include this partition only if you need them; cli11.cpp re-exports it.
